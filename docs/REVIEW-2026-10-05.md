### What the checked-in code does (and does not) establish

- The Twelve Data callback `on_event()` calls `check_position(price)` on every
  accepted price event. Its broad exception handler silently drops exceptions,
  so the CSV alone does not explain why a Twelve Data run failed to close.
- The `DATA_SOURCE=MT5` forward-test loop `run_mt5_test()` evaluates each closed
  candle but does **not** call `check_position()` or otherwise inspect the bar's
  high/low against the active trade. `evaluate_candle()` does not manage exits.
  If this checkout-equivalent code was deployed and MT5 was the feed at 07:20,
  the missing bar-exit check is a direct, plausible explanation for the open
  state; neither the historical feed mode nor deployed revision is confirmed.
- The current host sample identifies a simulator in MT5-feed forward-test mode,
  but does not establish the Oct 1 mode or the deployed Git SHA. Do not label the
  MT5 path a confirmed production root cause until those are checked.
- A restart restores the saved open trade; it does not replay prior candles or
  reconcile the crossed stop. `check_data.py` passes because the CSVs are
  structurally consistent and the saved status agrees with the ledger count; it
  does not test whether an open trade should already have crossed SL/TP.

**Do not hand-edit `status.json` or append a guessed close to `trades.csv`.** The

OHLC stop breach, but not an exact fill or the feed/revision used at the breach.

## Read-only host checks still needed

The following checks print the deployed revision, the specific MT5 feed unit's
state, safe candle metadata only, and engine startup/feed-mode lines around the
trade date. They do not print `.env` secrets or change host state. Please run
this on the host and paste the output:

```bash
echo '=== deployed engine revision ==='
sudo git -C /opt/bitcoin log -1 --format='commit=%H%ncommit_date=%cI%nsubject=%s' 2>&1

echo
echo '=== MT5 feed unit ==='
sudo systemctl show mt5feed-btc.service \
  -p LoadState -p ActiveState -p SubState -p MainPID -p ExecMainStartTimestamp \
  --no-pager 2>&1

echo
echo '=== current candle timestamps only ==='
sudo python3 - <<'PY'
import json
p = "/opt/bitcoin/mt5_last_candle.json"
try:
    d = json.load(open(p))
    for k in ("updated_at", "ts", "server_ts", "server_offset_s", "symbol"):
        print(f"{k}={d.get(k)}")
except Exception as e:
    print(f"Could not read candle file: {e}")
PY

echo
echo '=== engine startup/feed-mode lines around Oct 1 ==='
sudo journalctl --utc -u bitcoin-engine.service \
  --since '2026-09-30 00:00:00 UTC' --until '2026-10-02 00:00:00 UTC' \
  -o short-iso-precise --no-pager 2>&1 |
  grep -Ei 'Bitcoin Engine|Twelve|MT5 feed|feed file found|Restored OPEN|Stopping|Started'
```
